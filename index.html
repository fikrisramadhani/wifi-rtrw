Hanya update pelanggan yang tgl pasangnya cocok dengan filter di bawah. Berguna untuk koreksi pelanggan dari batch import tertentu.

Tambah Pelanggan

Posisi tunggakan/kredit saat aplikasi mulai dipakai. Positif = tunggakan, negatif = kredit, 0 = lunas. Contoh: 200000 = nunggak 200rb, -50000 = punya kredit 50rb.
⚠️ Saat diisolir, tagihan TIDAK bertambah. Saat status diubah ke Aktif lagi, tagihan akan dihitung dari tanggal aktif kembali.

📥 Import dari MikroTik PPP Secret

Cara pakai:
1. Buka winbox/SSH ke MikroTik Anda
2. Jalankan: /ppp secret export atau buka tab PPP → Secrets
3. Copy semua baris yang dimulai dengan add name=...
4. Paste di kotak bawah

Pemetaan otomatis: Awalan username akan dipetakan ke lokasi sesuai pengaturan, profile akan dipetakan ke paket.
Untuk pelanggan lama, isi tanggal sebelum "Tanggal Mulai Pencatatan" (default sudah otomatis). Sistem akan tagih semua dari tanggal mulai pencatatan.

💰 Bulk Update Saldo Awal

Cara pakai:
1. Siapkan data di Excel dengan 2 kolom: Username | Saldo Awal
2. Saldo Awal: positif = tunggakan, negatif = kredit, 0 = lunas
3. Copy data (tanpa baris judul) → paste di kotak bawah

Contoh:
p.budi 200000 → Pak Budi nunggak Rp 200.000
p.siti 0 → Bu Siti lunas
p.ahmad -50000 → Pak Ahmad punya kredit Rp 50.000

📋 Import dari Excel

Format paste (TAB-separated dari Excel):
Username | Nama | Alamat | HP | Paket | Lokasi (opsional)

Untuk paket, tulis kecepatannya saja: 10 Mbps, 20Mbps, dll.
Username adalah identifier unik (contoh: p.budi). Kalau kosong akan dibuat otomatis dari nama.
